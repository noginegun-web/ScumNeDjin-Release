# SCUM NeDjin

Публичный клиентский релиз панели управления SCUM NeDjin.
Функционал:
13 плагинов
Карточка игрока с возможность взаимодействия не входя в игру.
Доступ к панели с любого устройства при наличии логина и пароля.
Автовыдача с Wargm и многое другое .
## Установка

1. Остановите SCUM-сервер.
2. Распакуйте архив релиза в SCUM/Binaries/Win64.
3. Откройте ScumNeDjin/nedjin.ini.
4. Укажите свободный порт в port и замените Api_key на свой надежный ключ.
5. Запустите сервер и откройте панель: http://IP_СЕРВЕРА:PORT.

Подробная инструкция находится внутри архива: INSTALL_CLIENTS_RU.md и INSTALL_RU.txt.

## Важно
Возможны баги и не доработки , проект абсолютно бесплатный.
Возможны просадки по пингу , в ближайшем обновлении решим эту проблему.
Релиз не привязан к конкретному хостингу, IP или порту. Нужны FTP-доступ к папке сервера и открытый TCP-порт для панели.
