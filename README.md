# ScumNeDjin

Открытый исходный код панели управления и runtime-моста для выделенных серверов
SCUM. Оригинальный автор и сопровождающий проекта —
[`noginegun-web`](https://github.com/noginegun-web).

## Что находится в репозитории

- `src/native` — нативный `version.dll` и HTTP/bridge-слой;
- `src/ScumWarden.Server` — исходники панели ASP.NET Core;
- `ue4ss/Mods/ScumNeDjinBridge` — серверный UE4SS-мост;
- `ue4ss/ScumNeDjin` — конфигурационные шаблоны и веб-ресурсы.

Проект не содержит рабочих адресов, ключей, журналов, баз данных, резервных
копий или данных игроков. Он не включает игровые ассеты, извлечённые каталоги
и сторонние материалы без зафиксированного разрешения на распространение.

## Начало разработки

Соберите нативную часть и панель по [BUILDING.md](BUILDING.md). Для локальной
настройки используйте только свои конфиги и данные, на которые у вас есть
права. Полные границы публичной поставки описаны в
[PUBLIC_BOUNDARY.md](PUBLIC_BOUNDARY.md) и [ASSET_POLICY.md](ASSET_POLICY.md).
