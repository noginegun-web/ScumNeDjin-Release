# ScumNeDjin

Открытый исходный код панели управления и runtime-моста для выделенных серверов
SCUM. Оригинальный автор и сопровождающий проекта —
[`noginegun-web`](https://github.com/noginegun-web).

## Что находится в репозитории

- `src/native` — нативный `version.dll` и HTTP/bridge-слой;
- `src/ue4ss_cppmods` — исходники C++‑модулей UE4SS;
- `ue4ss/Mods/ScumNeDjinBridge` — серверный UE4SS-мост;
- `ue4ss/ScumNeDjin` — конфигурационные шаблоны и встроенная статическая
  веб-панель.

Проект не содержит рабочих адресов, ключей, журналов, баз данных, резервных
копий или данных игроков. Он не включает игровые ассеты, извлечённые каталоги
и сторонние материалы без зафиксированного разрешения на распространение.

## Начало разработки

Соберите нативную часть, C++‑модули UE4SS и панель по
[BUILDING.md](BUILDING.md). Для локальной настройки используйте только свои
конфиги и данные, на которые у вас есть права. Полные границы публичной поставки описаны в
[PUBLIC_BOUNDARY.md](PUBLIC_BOUNDARY.md) и [ASSET_POLICY.md](ASSET_POLICY.md).

Для модулей, которые должны автоматически работать с реально вошедшими
игроками, соблюдайте [правила runtime-безопасности](docs/PLAYER_AUTOMATION_SAFETY.md).

## Граница runtime

Рабочий сервер не требует отдельного ASP.NET-приложения: `version.dll` запускает
свой HTTP/API-слой и раздаёт панель из `ScumNeDjin/web`, а UE4SS-мост выполняет
игровые операции. Публичный API намеренно не предоставляет произвольную
серверную консоль. Встроенный, выключенный по умолчанию server-command fallback
остаётся внутренним транспортом для проверенных модулей и не является отдельным
проектом или публичной точкой управления.
