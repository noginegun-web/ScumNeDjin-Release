# Contributing

1. Fork the canonical repository and create a focused branch.
2. Keep changes small, document user-visible behavior and add a relevant check.
3. Do not commit credentials, private data, game assets or unlicensed material.
4. Sign every commit with `git commit --signoff`.
5. Open a pull request against the default branch and complete the template.

By contributing, you confirm that you have the right to submit the change and
license it under [LICENSE](LICENSE). See [DCO.md](DCO.md) and
[ASSET_POLICY.md](ASSET_POLICY.md).

For changes made outside the canonical repository, include the fork URL, base
commit, comparison URL, validation results and a concise description of the
change. Preserve [NOTICE](NOTICE), [COPYRIGHT.md](COPYRIGHT.md) and project
attribution in derivative distributions.
