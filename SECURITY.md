# Security policy

Do not publish credentials, personal data, database extracts, logs, crash
dumps or private environment details in public issues, pull requests or
discussions.

For a potential vulnerability, contact the project steward through the support
channel shown in the panel and provide a minimal reproduction without sensitive
data. Do not publish a working exploit until the maintainer has had a reasonable
opportunity to assess it.

Reports should state the affected version, prerequisites, impact, reproduction
steps and a safe remediation proposal.
